# 方法记录：Linux 静态恢复受保护 Python 模块

- 日期：2026-09-07
- 场景：用户持有 Windows Python 程序，业务源码遗失，只有 Linux 分析环境。
- 路由：reverse-skill R7 / radare2；主代理承担逆向、复核和文档角色。
- 先验：普通 PyInstaller 提取只能得到 PyArmor 入口，不能据此认定业务代码不可恢复。
- 有效路径：固定原件指纹，读取原生运行时导入/导出，审阅静态解包工具，提取保护载荷并解析函数字节码。
- 复核：从原始容器重新提取后重复恢复，比较完整反汇编哈希；这是可重复性检查，不是独立工具验证。
- 限制：自动反编译的成功退出码可能伴随空输出、错误缩进和无法编译的表达式。逐条指令优于失败草稿；分支偏移必须人工核对。
- 证据处理：保留失败草稿和日志；密钥与中间解密载荷不进入交付目录；原始资产保持不变。
- 后续适用性：适用于同类保护布局的调查线索，不能保证其他 Python/PyArmor 版本也可恢复。
- 发布状态：仅本地记录，没有提交到技能上游或其他外部服务。
