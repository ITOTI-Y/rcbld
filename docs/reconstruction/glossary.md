# RCBld 重构领域词汇表（讨论稿）

> **当前基准（2026-09-07）**：用户指定 [andersonspy/RCBIdEng](https://github.com/andersonspy/RCBIdEng) 进行协议确认，开发环境确定为 Python 3.9.11，重构项目使用 `dev`。上游 v1.3.0 正式发行 ZIP 与用户文件指纹一致；固定仓库提交中的 EXE 不同，不能代替正式发布包。仓库已提供 8 个 `.sim` 和 25 个历史 CSV，没有 `.sol` 或项目 Python 源码。详见 [上游协议核对](engine-protocol.md) 和 [发布包记录](engine-v1.3.0.md)。原文旧 EXE 的 CLI、算法和缺陷仅作历史线索；运行行为仍待 Windows/Rhino 验收。

状态：从归档源码、手册及引擎静态字节码提取，并按用户 Q1–Q11、中国优先及 English-first/i18n 要求更新产品边界；具体字段、单位与模型契约仍为讨论稿，不是已批准的新 API。

证据索引见 [evidence.md](evidence.md)；决策进度见 [decisions.md](decisions.md)。

| 术语 | 本项目语义 | 现有表示 / 证据 | 重构时必须区分 |
|---|---|---|---|
| RCBldGH | Rhino/Grasshopper 建模、组装、导出、调用及读结果的插件 | 手册 §1；`RCBldGH.csproj` | 宿主插件不是计算引擎 |
| RCBldEng | 灰箱 RC 建筑热工/能耗计算引擎 | 手册 §1；EXE 内 `RCBldEng.py`、`simulation.py` | 计算算法与进程运行封装不是同一责任 |
| 建筑能耗模型（Building Energy Model） | 建筑、热区、工况、材料及能源系统的完整模拟输入 | `Components/7.simulation/BEM_New.cs:32-50,61-139,184-279` | 旧组件名 BEM 有歧义；不等同于下述控制等级 |
| 建筑能源管理等级（Building Energy Management） | D/C/B/A 四类自动化/管理等级 | `Modules/BEM.cs:3-20`；EXE `lib.py` 的 `BEM_Sys` | 建议新模型用明确的 ManagementClass 名称，而非继续复用 BEM；未决 |
| 几何模型 | Rhino Brep、Surface、参考平面及其拓扑 | 手册 §3.1.1；`BEM_New.cs:67-72` | 几何实体不等于热工实体；米是现有输入要求，不是现有自动换算能力 |
| 热区（Thermal Zone） | 参与热平衡的空间计算单元，具有几何量、工况及边界；用户选择预先划分热区的闭合 Brep，包含空调与非空调区，围护以平面为主 | 手册 §3.1.1；EXE `lib.py:884` 的 `Pre_Calculation.getZoneInfo`；用户 Q5=A、Q10=B、Q11=A | 不强制等于真实房间；主入口一 Brep 对应一热区是模型契约建议；需求确认不代表引擎能力已验证 |
| 非空调区（Unconditioned Zone） | 不主动维持供暖/制冷设定温度的热区，其自由室温及与相邻区的传热仍参与计算 | 用户 Q10=B；ADR-012 | 不等于室外、绝热、无人或无内部得热；不能用极端温度设定伪造支持，也不自动包含自然通风气流网络 |
| 平面围护（Planar Envelope） | 热区边界由平面构成，包括非正交平面和坡屋顶；曲面由用户先简化 | 用户 Q11=A；ADR-013 | 闭合 Brep 不自动满足平面性；面积、法线、倾角与边界类型分开；不把坡面静默投影或按单个采样法线接受曲面 |
| SuperBrep | 新版旧代码中混合几何、围护、工况、计划及太阳数据的载体 | 手册 §3.1.1；`BEM_New.cs:70-121,303-398` | 属于旧实现对象，不应直接当作新领域模型定义 |
| 围护/边界（Envelope / Boundary） | 热区与室外、地面或相邻热区间的传热边界；包含窗与不透明部分 | EXE `lib.py:884,1044` 的热区及围护预处理 | 物理表面、按朝向汇总的围护设置、相邻区接触面积应分别表达 |
| 邻接关系（Adjacency） | 热区间墙、地板、天花的邻区名称及接触面积 | EXE `lib.py:884` 的 `Adjacent … Zone Name and Contact Area` 字段 | 需要明确双向一致性、接触面积、外边界归属；不能仅靠字符串拼接隐含 |
| 材料/构造热工参数 | 传热、吸收、发射及窗 SHGC 等输入 | 手册 §3.1.1；`NewRunComp.cs:273-369` 的材料段 | U 值、热阻 R、反射率、发射率不可混称；是否支持分层构造未决 |
| 使用工况（Program） | 人员、代谢、设备、通风渗透、生活热水、窗开启、夜间通风、照明与 HVAC 模板 | 手册 §3.1.1；EXE `lib.py:884` | 工况参数与随时间变化的比例/设定值分开 |
| 地区工况预设（Regional Program Preset，暂称） | 有明确来源和适用条件的人员、照明、设备、温度及日程配置；中国办公/住宅优先，允许逐热区覆盖 | 用户 Q9=B 及国际化要求；ADR-010 | 预设不是规范认证；地区不同于界面语言；规范限值、典型值和用户覆盖值分别追溯，具体数据尚未核实 |
| 日程（Schedule） | 日内时段、工作日/周末值及月度引用组成的时间规则 | `CenGenerator.cs:49-79`；EXE `lib.py:185,769` | 温度设定值、无量纲使用比例及渗透比例不是同一种数值 |
| BUS（Building Use Schedule） | 人员、设备、照明、HVAC、渗透等工作日/周末使用计划 | `NewRunComp.cs:253-260`；EXE `lib.py:802-803`，10 列计划 | 不等于端口 `BUS Data` 或 `BusData` 类 |
| ITSS（Indoor Temperature Setpoint Schedule） | 工作日/周末采暖与制冷温度设定计划 | `NewRunComp.cs:243-250`；EXE `lib.py:805-806`，4 列计划 | 与计算输出的室内温度不同 |
| BUS Data / BusData / Data | 旧运行组件接收的聚合输入包，含整个建筑模型所需数据 | `BEM_New.cs:46-50,67-139`；`NewRunComp.cs:113-201` | 旧名称误导；建议统一称建筑模型输入，具体类型名未决 |
| HVAC / DHW / Pumps | 空调系统、生活热水及泵系统参数 | 手册 §3.1.1-3.1.2；`NewRunComp.cs:388-418` | 负荷需求、系统效率、最终购入能源量需区分 |
| 天气数据 | EPW，或引擎能读取的特定 CSV 格式 | 手册 §3.1.2；EXE `weather.py:28-74` | 日期、时区、每小时区间、缺测与闰年规则未形成验收契约 |
| 太阳输入（Solar Input） | 每个热区的窗与不透明部分太阳序列 | `NewRunComp.cs:209-228`；EXE `RCBldEng.py:32-45` | `.sol` 顺序为窗序列在前、不透明序列在后；单位与时间轴仍需专项核实 |
| 窗/遮阳输入模式 | 默认参数化窗墙比/简化遮阳，也支持实际窗、遮阳与周边建筑几何 | 用户 Q8=C；ADR-009 | 模式可共存不等于同一面重复计窗或同一遮挡重复折减；周边遮挡物不是热区，显式几何仍需转成经核实的太阳输入 |
| 比选方案（Design Variant，暂称） | 用户提交的一套待比较建筑模型与配置，主要面向办公或住宅建筑 | 用户 Q3、Q6；新增领域语义建议，不是旧 EXE 对象 | 方案不是运行编号；同一方案可以有多次运行，跨用途能耗差异不自动代表设计优劣 |
| 比选批次（Comparison Batch，暂称） | GH 一次提交的一组方案，依次计算后汇总 | 用户 Q6=B | 成组提交不等于并行计算；方案数未定，不写死上限，也不承诺无限规模 |
| 模拟任务（Simulation Run） | 一次确定模型、天气、参数和输出目录的运行 | `NewRunComp.cs:124-165,439-504`；EXE `RCBldEng.py:16-60` | 工程、建筑标签、运行编号不是同一标识；旧实现默认反复使用 first_run |
| 模拟结果（Simulation Result） | 逐时建筑指标、月度聚合、各区室温及运行诊断 | EXE `simulation.py:751-819`；三个 Reader | 数值字段、单位、时间轴、能源类型不能由固定列号猜测；文件存在也不代表本次运行成功 |
| 国际化（Internationalization / i18n） | 英文为主界面及基准文本，通过独立文本资源实现多语言支持；语言、地区资料、单位显示与天气时间规则分开 | 用户 Q9 补充及 Q10–Q11 回答时的语言要求；ADR-011 | 翻译展示文本，不翻译稳定标识或引擎协议；切换语言不改变工况；简体中文交付为建议，不能推定所有语言、国家模板或跨平台引擎均已支持 |

## 暂定关系图（描述职责，不承诺实现框架）

```text
几何模型 ──边界识别/邻接──> 热区 + 热边界
材料/构造 + Program + Schedules ──关联──> 热区模型
热区模型 + 建筑基础 + 能源系统 + 天气 ──组装──> 建筑能耗模型
建筑能耗模型 + 运行参数 ──适配引擎──> Simulation Run
Simulation Run ──计算/解析──> 时序结果 + 聚合结果 + 诊断
```

已确认：Q4 旧定义干净切换；Q5 预划分闭合 Brep 入口；Q6 办公/住宅的顺序批量比选，规模未定；Q7 固定系统与使用工况比较建筑设计变量；Q8 参数化/显式窗与遮阳双路径；Q9 有据可改的中国优先工况预设；Q10 空调/非空调区共同建模；Q11 平面围护，含非正交平面和坡屋顶，曲面由用户先简化；English-first，通过 i18n 实现多语言支持。尚未定稿：非空调与坡面需求的引擎映射、具体太阳输入契约、预设来源及数值、额外语言与地区交付清单、单位/日历约束、模型持久化格式与稳定 ID。不得将需求已确认等同于原引擎能力已验证；完整方案待复核，详见 [决策记录](decisions.md)。
